# 花谱 · Flower Codex

**这束花，该送什么？**

一个纯静态的花与场合对照册，写给原创角色写手、画手与考据党。100 条花、9 个场合、6 组花束配方；花语按中式 / 西式 / 日式分列，并标注对猫狗、儿童与误食的风险。

## 本地预览

最简单：双击 `index.html`。

或者起一个本地静态服务器（推荐，便于测试深链接）：

```bash
cd Flower_map
python3 -m http.server 8000
```

然后打开 <http://localhost:8000/>。GitHub Pages 可直接把整个目录推到仓库根目录（或 `docs/`）发布，所有路径都是相对的，无构建步骤。

## 文件

```
index.html          页面骨架
styles.css          纸张 / 墨 / 胭脂 / 藕粉；无渐变，细线，A5 打印样式
app.js              SVG 花形生成、搜索筛选、日历、场合反查、抽屉、深链接、打印
logo.svg            花谱印章式花标（页眉 / 页脚 / favicon）
flowers-list.html   独立花单：100 条一览、搜索、排序、复制 ID、打印
flowers-list.csv    当前花单快照（UTF-8 BOM，供表格软件迭代）
data/flowers.js     100 条花数据（window.FLOWERS）
data/bouquets.js    9 个场合方案 + 6 组花束配方（window.OCCASIONS / window.BOUQUETS）
qa/                 无头浏览器自检截图与 A5 PDF（非站点运行依赖）
```

## 花单 / 迭代

打开 [flowers-list.html](flowers-list.html)，或直接看 [flowers-list.csv](flowers-list.csv)。

- 花单页按编号列出全部 100 条，包含 ID、中英文名、学名、科属、花期、花色、场合、毒性；点花名可直接进入站内详情。
- 每行可「复制 ID」，方便对照 `data/flowers.js` 改稿。
- CSV 是当前快照；改完数据后需要重新导出/更新 CSV。

## 视觉

- 色板以纸张 `#F7F2E9`、墨 `#211C17`、胭脂 `#A0432B`、藕粉 `#C98B8B` 为底，加了金 `#C08A2E` 与鼠尾草绿 `#5F6D4C` 作为花标/叶片的强调色。
- 页眉、页脚、首屏右侧使用印章式花标；卡片左侧用该花主色做细色条，花束卡左侧用配方主色。
- 标题宋体，正文无衬线；花图为 SVG 形态示意，不用照片。
- 夜晚模式使用深墨/紫褐底、奶油字、珊瑚红与琥珀黄；页眉月亮按钮可切换。

## 已实现

- 搜索：中文名 / 英文名 / 学名 / 别名 / 科属 / 花形 / 产地 / 花语 / 文化 / 禁忌 / 创作提示 / 搭配；结果高亮。
- 筛选：花期月份、花色、场合、花香、毒性风险、花形。
- 按场合反查：9 个场合，给出「为什么合适 / 不要送」、3–5 支组合、配色与一句花卡文案。
- 花期日历：12 个月横条；点月份看当季花；卡片带迷你花期条。
- 花束配方：6 组可打印 A5 花卡；花材可点回详情。
- 详情抽屉：学名、科属、别名、形态、花径、株高、花香、花期、花语三文化、场合/禁忌、毒性、产地/生境、瓶插、压花、文化/诗词/神话、创作提示、常见误用、冷知识、搭配。
- 随机一支、`#id` 深链接、`/` 聚焦搜索、`Esc` 关闭抽屉、每页 15 条分页、移动端 390px 无横向滚动。
- A5 打印：详情、花束配方、花篮清单均可打印；打印卡带免责声明与「形态示意」标注。
- **深度搜索**：花名、学名、别名、花语、文化注记、禁忌、创作提示、搭配都能搜；结果高亮，并在卡片内显示命中的文化/禁忌片段。
- **URL 状态**：搜索词、月份、花色、场合、花香、毒性、花形、页码同步到 `?q=...`，可直接分享筛选结果。
- **花篮**：卡片右上角「＋」或详情抽屉加入；`localStorage` 保存，最多 8 朵。
- **对比**：花篮里勾选 2–4 朵，并排看花期、花色、花香、毒性、三文化花语、场合、禁忌与搭配。
- **禁忌检查**：按「猫狗 / 儿童 / 探病 / 婚礼 / 悼念 / 忌浓香」做初筛，标出风险与相近替代花。
- **花篮导出 / 打印**：导出 CSV，或打印 A5 选花清单。
- **今日花签**：按日期固定一支花，可保存 PNG 分享卡。
- **夜晚模式**：页眉月亮按钮切换，`localStorage` 记住；打印卡保持纸色。
- **键盘**：`/` 聚焦搜索，`↑ / ↓` 在结果卡之间移动，`Enter` 打开详情，`Esc` 关闭。

## 数据与安全说明

- 花语是文化流变与花艺常用说法的整理，不是植物学结论，也不宣称唯一正确。日式花语尤其因花店、地区与年代而异。
- 毒性标注只用于创作与安全提醒，不构成兽医、医疗、食用或药用建议。不要据此食用、药用，也不要让宠物/儿童啃咬花材。
- 花图是按花瓣数、花形与花色生成的 SVG「形态示意」，不是照片，不能替代植物学鉴定。
- 只讨论园艺栽培花材；不推荐受管制或保护植物，不提供野外采摘、食用或药用建议。
